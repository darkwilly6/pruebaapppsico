# Mi Espacio — prototipo

Prototipo navegable e **instalable** (PWA) de *Mi Espacio*, el acompañamiento de Método Emperatriz (Diana Ayala).

> **Datos ficticios.** No tiene cuentas, base de datos, cifrado ni el backend real. Al recargar vuelve al inicio. No escribas información personal.

## Ver en el navegador
Necesitas Python o Node. En esta carpeta:
```
python -m http.server 5500
```
Abre http://localhost:5500/

## Instalar en el teléfono
La app es una PWA. Para instalarla hace falta abrirla desde una dirección **https** (un hosting). Una vez publicada:
- **Android (Chrome):** menú ⋮ → «Instalar aplicación» / «Agregar a pantalla de inicio».
- **iPhone (Safari):** Compartir → «Agregar a pantalla de inicio».
